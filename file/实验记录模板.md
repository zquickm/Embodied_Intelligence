# 实验记录模板

> 创建：2026-10-21
> 用途：每个实验（训练一次、改一个超参、换一个奖励项）都复制一份本模板填。
> 为什么需要：**RL 结果的方差远大于监督学习**，不记种子和配置，事后无法区分"真的变好了"和"这次运气好"。

---

## 使用方式

1. 复制本文件到 `file/experiments/` 下，命名 `YYYY-MM-DD_<实验名>.md`
2. 填完"配置"和"结果"两节
3. 训练曲线图存到 `file/assets/`，在本文件里引用
4. **训练完立刻填**，不要凭记忆补——事后补的记录必然漏掉关键细节

---

## 一、基本信息

| 项 | 内容 |
|---|---|
| 实验名 | （例：`a1_mnist_baseline`） |
| 日期 | YYYY-MM-DD |
| 对应阶段 | （例：A1） |
| 目的（一句话） | （例：验证手写训练循环能达到 >98%） |
| 假设（可证伪） | （例：baseline 应达到 98.5%±0.3%，若低于 97% 说明数据增强或归一化有问题） |

**为什么要写"假设"**：没有假设的实验，跑出来的任何结果都能被解释成"成功"。先写下预期，才能发现自己错了。

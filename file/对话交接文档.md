## 8. 已经被剧透的两个坑（记录在案，但用户仍需自己踩）

这两个坑助手已经踩过并写进总计划 6.2，**但因为提前告知，剥夺了用户自己发现的机会**。写 C3 代码时用户仍会遇到：

1. **手工构造 `ManagerBasedRLEnv` 必须先 `resolve_presets()`**
   Isaac Lab 3.0 用 `PresetCfg` 把同一任务的多种预设（`default`/`hold`/`diffik`/`newton_ik`）包在 cfg 里。不展开时 `actions.arm_action` 是 Preset 对象而不是动作配置，`validate_config()` 会误判成启用了 `hold` 预设，抛：
   ```
   ValueError: The 'hold' preset requires the Franka joint-position action
   ```
   官方 `isaaclab train/play` CLI 自动做了这一步，手工 `ManagerBasedRLEnv(cfg=...)` 时不会。

2. **`env.reward_manager._step_reward` 形状是 `(num_envs, num_terms)`**
   第一维是并行环境，第二维才对应 `active_terms`。按 `(num_terms, num_envs)` 读会得出"权重 ×100 只有 21 倍""权重设 0 却不是 0"的错误结论。

## 9. 其他已知坑（环境类，可直接照做）

| 坑 | 现象 | 解法 |
|---|---|---|
| 中文控制台编码 | `UnicodeEncodeError: 'gbk' codec ...` | `PYTHONUTF8=1`（activate.ps1 已含） |
| `.ps1` 无 BOM | PowerShell 5.1 解析报错、中文乱码 | 含中文的 `.ps1` 必须存 **UTF-8 with BOM** |
| pip 升级 | 升到 26 触发 PEP 658 校验，装 Isaac 时 `BadMetadata` 崩溃 | **禁止升级，锁 25.3** |
| 装包破坏环境 | 版本链断裂 | **任何 `pip install` 前先 `--dry-run`**，确认只有新增无变更；装完跑一次回归训练 |
| `Get-Content` 读中文 | 乱码 | 加 `-Encoding UTF8` |
| git push 失败 | `schannel: failed to receive handshake` 或 `TLS connect error: unexpected eof` | 先重试（常是网络抖动）；仍失败用 `git -c http.sslBackend=openssl push`。**代理 7897 现在返回 407 需要认证，别用代理方案** |
| 训练日志污染仓库 | 仓库里出现 `logs/` | 一律在 `D:\isaac\work` 跑训练；`.gitignore` 已加 `logs/` |

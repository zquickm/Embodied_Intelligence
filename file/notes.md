# 调研笔记：阶段一现成底盘选择与验收

## 工作区依据

- 总计划指定 Ubuntu 24.04、ROS 2 Jazzy，并要求底盘带编码器、闭环控制、可用供电、文档化通信接口，以及 ROS 2 驱动或 Python SDK。
- 阶段一的边界是选型、购前核验与基础到货验收；通信细节、ROS 2 标准化接入和里程计校准分别属于阶段二、三。
- 百元级预算不能默认买到资料完整的闭环底盘；应比较缺件补齐后的总成本。

## 待核对

- ROS 2 Jazzy 官方文档确认 Ubuntu 24.04 Noble 的 64 位 x86 与 ARM 均受支持。
- ROS 2 官方说明中，话题用于连续数据流；可用 `ros2 topic list`、`info`、`echo`、`hz` 检查话题类型、发布者、内容和频率。
- ros2_control Jazzy 的差速控制器文档包含编码器位置反馈、里程计和速度命令超时参数；这可以作为筛选底盘功能的通用依据，但不能据此假定厂家驱动一定使用相同参数名。
- 具体厂商命令必须等待型号和文档确定后填写，不能凭空假定话题名、波特率或速度单位。

## 方案边界

- 选型阶段只要求证明资料、控制、反馈和安全机制存在，不提前开发新驱动。
- 到货验收按“静态检查—悬空低速—落地低速—反馈检查—断联测试”的顺序逐步放行。
- 未确认电压、极性和连接器定义前不通电；首次测试不安装机械臂。

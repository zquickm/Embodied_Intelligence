## 1. 载荷：将来要放到底盘上的质量

估算依据来自总计划的选型（阶段 4 SO-101 从臂、阶段 8 RPLIDAR A1、阶段 9 D435i），数值全部**未实测**，属保守估计。到阶段 4 装完机械臂后用电子秤实测替换。

| 部件 | 估算质量 | 是否已实测 | 估算依据 |
|---|---:|---|---|
| 机械臂从臂（SO-101，含夹爪结构） | 0.8 kg | 否 | 总计划阶段 4 选型，含全部电机与线材的保守估 |
| 机械臂支架和安装板 | 1.0 kg | 否 | 铝板 + 支柱 + 螺丝，保守估 |
| 上位机 | **0 kg** | — | **2026-10-17 用户决定：不上车**。阶段 6 前全部用现有电脑（WSL2）验证，总计划阶段 6 也写明"上位机先使用已有电脑验证"。若将来重新决定上车，本表需重新计算 |
| 电池和稳压模块 | 1.5 kg | 否 | 成品电池包 + 多路稳压，保守估 |
| 相机、雷达和支架 | 0.7 kg | 否 | D435i 约 0.18 kg、RPLIDAR A1 约 0.19 kg、双支架约 0.3 kg |
| 其他线束与外壳 | 0.5 kg | 否 | 预留 |
| **上装合计** | **≈ 4.5 kg** | — | 上述之和 |
| **所需额定载荷 = 合计 × 1.5** | **≈ 7 kg** | — | 初筛线：底盘额定载荷 ≥ 7 kg，且厂家须同时给出载荷条件（重心高度、加减速、地面） |

注意：机械臂前伸会产生倾覆力矩。"静态放得下"不代表"运动时不翻"，筛选时把厂家载荷条件当成硬约束记录。

## 3. 控制与反馈硬门槛（已冻结 ✅）

以下六项全部是硬门槛，缺一即在第三步否决检查中淘汰候选，**任何预算下都不放宽**：

- [x] 能从电脑通过 USB、串口或有文档的网络接口控制，不只支持手机遥控。
- [x] 能设置前进速度和转向速度，且速度单位或换算关系有说明。
- [x] 有左右轮编码器，SDK 或驱动能读到轮速、编码器计数或里程计中至少一种真实反馈。
- [x] 有明确的停止命令。
- [x] 上位机停止发命令或通信断开后，底盘能在可配置或有说明的短时间内自动停车。
- [x] 能获得准确的控制板型号、固件版本和接口资料。

## 4. 预算

整套总价按下式统计，不是只看裸车架价格：

`整套总价 = 底盘 + 运控板 + 电池 + 充电器 + 通信线/转换器 + 缺失轮组或编码器 + 运费 + 必要维修`

- **预算上限：≤ 100 元**（2026-10-17 用户决定，"先"按当前阶段理解，后续可调整）
- 规则已定（沿用总计划）：若 ≤ 100 元只能买到裸车架、未知控制板或坏电池，则本阶段**保持仿真或借用设备**，不为"先有实物"购买无法开发的残套。
- 若日后放宽预算，本表直接复用，从第二步"收集 3 个候选"重新进入。

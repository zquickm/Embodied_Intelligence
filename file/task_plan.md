# 任务计划：细化具身智能阶段一

## 目标

把现有“阶段 1：选择并验收现成底盘”细化为可以逐项执行、记录和判定通过与否的操作方案。

## 阶段

- [x] 阶段 1：读取现有总计划，确认阶段一边界
- [x] 阶段 2：核对当前官方环境与通用验收依据
- [x] 阶段 3：编写详细执行方案、模板和验收表
- [x] 阶段 4：复核安全性、可执行性并交付

## 关键问题

1. 买前必须冻结哪些载荷、尺寸、接口和资料要求？
2. 如何判断卖家展示的是可开发底盘，而不是只能遥控的玩具车？
3. 到货后如何在不损坏设备的前提下完成通电、运动、反馈和失联停车验收？
4. 哪些证据缺失时必须暂缓购买或退货？

## 已作决定

- 不在型号和机械臂载荷尚未确定时推荐单一底盘型号。
- 优先复用厂家驱动、SDK、URDF 和固件，不安排自研控制板与电机固件。
- 阶段一只做采购决策和基础验收，ROS 2 深度接入留到阶段二、三。

# 阶段一候选核实记录（≤ 100 元预算初查）

- 日期：2026-10-17
- 目的：进入第二步"收集 3 个候选"之前，先核实 ≤ 100 元预算是否存在能通过否决检查的完整整套，避免把时间花在注定超预算的询价上。
- 结论存入《底盘需求表.md》未知项 U5。

## 结论

**≤ 100 元：不存在满足六项硬门槛的完整整套。** 按《阶段一详细实行步骤.md》第 3.4 节与总计划规则，默认分支为"保持仿真或借用设备，不为'先有实物'购买无法开发的残套"。

## 价位现实（2026-10-17 网络初查，具体候选仍需第二步实询验证）

| 价位 | 能买到 | 对照六项硬门槛 |
|---|---|---|
| ¥7–30 | 裸车架 + TT 电机（无编码器、无控制板） | ✗ 无编码器反馈；✗ 无运控板/固件资料；需自己写电机固件——总计划明确排除 |
| ¥88–209 | 两轮**自平衡车**套件（STM32 + 520 编码器电机） | ✗ 形态不符：平衡车不是差速底盘，控制问题完全不同；资料面向平衡控制而非差速里程计 |
| ¥24–80 | 单买 STM32 运控板 | 只是部件；配齐编码器电机、电池、车架后总价仍超 100 元 |
| ¥150–400 | 2WD/4WD 差速底盘（编码器电机 + STM32 + SDK/ROS 资料） | ✓ 唯一可能满足六项门槛的形态，但超预算约 50%–300% |

参考：淘宝"STM32 平衡车底盘套件"约 ¥209，麦轮/4WD ROS 套件常见 ¥299–359；AliExpress 上带 12V 编码器电机的 ROS 底盘约 $100 起，370/520 编码器电机套件约 $28–77，裸 TT 车架 $7–15。

## 含义与下一步

1. 若维持 ≤ 100 元：阶段一结论 = **暂不购买，保持仿真/借用**。需求表与六项门槛存档，日后放宽预算可直接复用，从第二步重新进入。
2. 开放项（需求表 U6）：二手渠道（闲鱼等）偶有 100–300 元的二手 ROS 整车。若愿意蹲守，仍按六项门槛验收，不降标。
3. 提示：六项硬门槛里最容易在低价位上被"省掉"的是编码器反馈和断联停车——这两项恰恰是阶段三导航能不能做起来的前提，砍掉它们等于买回一个阶段三作废的底盘。

## 最终决定（2026-10-19）

用户在"维持归档 / 蹲二手 / 放宽预算"三个分支中选择：**维持 ≤ 100 元预算归档，暂不购买，继续纯仿真。**

- 需求表与六项硬门槛存档，日后放宽预算直接从《阶段一详细实行步骤.md》第二步重新进入，无需重做需求冻结。
- 主线转入仿真支线：**阶段 1S（仿真感知入门——相机 + ArUco）**，零采购，为总计划阶段 9（深度）、阶段 11（语义地图）、阶段 12（ArUco 标定）打底。见《阶段1S详细操作步骤.md》。
